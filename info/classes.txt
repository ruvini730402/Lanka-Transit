=== RELATIONSHIPS FOR DIAGRAM ===

COMPOSITION:
   Auth ◆──── User (Auth contains User)
   Auth ◆──── Database (Auth uses Database)
   
DEPENDENCY:
   User -----> Database (User depends on Database)
   Bus -----> Database (Bus depends on Database)
   Booking -----> Database (Booking depends on Database)
   Payment -----> Database (Payment depends on Database)
   Seat -----> Database (Seat depends on Database)
   BookingCancellation -----> Database (BookingCancellation depends on Database)

ASSOCIATION:
   User ──── Booking (1:many - User has many Bookings)
   User ──── BookingCancellation (1:many - User has many Cancellation requests)
   Bus ──── Booking (1:many - Bus has many Bookings)
   Bus ──── Seat (1:many - Bus has many Seats)
   Booking ──── Payment (1:1 - Booking has one Payment)
   Booking ──── BookingCancellation (1:many - Booking can have multiple cancellation requests)
   Admin ──── BookingCancellation (1:many - Admin processes many cancellation requests)

=== DIAGRAM SYMBOLS ===

◆──── Composition (contains/owns)
-----> Dependency (uses/depends on)
──── Association (related to)
