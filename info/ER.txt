ER Diagram - Lanka Transit (Updated with Extended Schema)

=== ORIGINAL TABLES ===

User
PK ID INT NOT NULL
Name VARCHAR(100) NOT NULL
Email VARCHAR(60) NOT NULL
PasswordHash VARCHAR(255) NOT NULL
PhoneNumber VARCHAR(10) NOT NULL
Role ENUM('administrator','guest user','registered user') NOT NULL
RegistrationDate TIMESTAMP DEFAULT CURRENT_TIMESTAMP

Booking
PK ID INT NOT NULL
FK UserId INT
FK BusID INT
SeatNumber VARCHAR(6) NOT NULL
BookingTime TIMESTAMP DEFAULT CURRENT TIMESTAMP
Status ENUM('confirmed','cancelled','completed') NOT NULL
PhoneNumber VARCHAR(10) NOT NULL
Fare DECIMAL(10,2) NOT NULL

Feedback
PK ID INT NOT NULL
FK UserId INT
FK BusId INT
Comment TEXT
Rating INT
CreatedDate DATE

Incident
PK ID INT NOT NULL
FK UserId INT
FK AdminId INT
FK BookingId INT
Description TEXT
Status ENUM('submitted','in progress','resolved') NOT NULL
ReportedDate DATE
ResolvedDate DATE

Admin
PK ID INT NOT NULL
Email VARCHAR(60) NOT NULL
PasswordHash VARCHAR(255) NOT NULL
Name VARCHAR(100) NOT NULL
PhoneNumber VARCHAR(10) NOT NULL

Bus
PK ID INT NOT NULL
FK RouteId INT
FK AdminId INT
BusNumber VARCHAR(7) NOT NULL
Capacity INT NOT NULL
LastUpdate DATE

Payment
PK ID INT NOT NULL
FK BookingId INT NOT NULL
PaymentMethod VARCHAR(50)
Status ENUM('success','failed') NOT NULL
Amount DECIMAL(10,2)
PaymentDate TIMESTAMP DEFAULT CURRENT_TIMESTAMP
TransactionId VARCHAR(100)

Receipt
PK ID INT NOT NULL
FK PaymentId INT NOT NULL
PdfUrl VARCHAR(255) NOT NULL
GeneratedDate DATE

Seat
PK ID INT NOT NULL
FK BusID INT
SeatNumber VARCHAR(6) NOT NULL
Status ENUM('available','booked')
GenderPreference ENUM('male','female','other') NOT NULL
IsLadySeat BOOLEAN

Schedule
PK ID INT NOT NULL
FK BusID INT
DepartureTime DATETIME NOT NULL
ArrivalTime DATETIME NOT NULL
Fare DECIMAL(10,2) NOT NULL

Route
PK ID INT NOT NULL
Origin VARCHAR(50)
Destination VARCHAR(50)
Stops TEXT

Location
PK UniqueID INT NOT NULL
Name VARCHAR(100) NOT NULL
Type ENUM('terminal','stop')

=== EXTENDED RELATIONSHIPS ===

Original Relationships:
- A **User** makes a **Booking**
- A **Booking** reserves a **Seat**
- A **Booking** generates a **Payment**
- A **Payment** generates a **Receipt**
- A **User** submits a **Feedback**
- A **User** reports an **Incident**
- An **Admin** resolves an **Incident**
- An **Admin** manages a **Bus**
- A **Bus** contains many **Seats**
- A **Bus** has a **Schedule**
- A **Bus** operates on a **Route**
- A **Route** includes multiple **Locations**

Extended Relationships:
- **User** extends to **User_2** (1:1 relationship)
- **Bus** extends to **Bus_2** (1:1 relationship)
- **Route** extends to **Route_2** (1:1 relationship)
- **Schedule** extends to **Schedule_2** (1:1 relationship)
- **Booking** extends to **Booking_2** (1:1 relationship)
- **Seat** extends to **Seat_2** (1:1 relationship)
- **Payment** extends to **Payment_2** (1:1 relationship)
- **Feedback** extends to **Feedback_2** (1:1 relationship)
- **Incident** extends to **Incident_2** (1:1 relationship)
- **Receipt** extends to **Receipt_2** (1:1 relationship)
- **Booking_2** references **Schedule** (many:1 relationship)
- **Incident_2** can be assigned to **Admin** (many:1 relationship)
- **Admin** creates **Announcements** (1:many relationship)
