Chapter: Implementation

Overview
This section implements each module from the ER/design diagram using the actual project files. The stack is PHP + MySQL (PDO), Bootstrap for UI, and environment-driven config. Below, every entity/module from the design is mapped to concrete classes, pages, algorithms, and code segments in this repository.

Module-by-Module Implementation

1) Database Access Layer
The Database class (`classes/Database.php`) implements a robust PDO-based connection layer with environment-driven configuration security. The implementation leverages the DatabaseConfig class through environment variables loaded via EnvLoader, ensuring production credentials remain secure. Key methods include `getConnection()` which establishes PDO connections with proper error handling and logging, `executeQuery()` for prepared statement execution with parameter binding, and static utility methods `sanitizeInput()` and `validateInput()` for XSS prevention and data validation. The class uses PDO::ERRMODE_EXCEPTION for comprehensive error handling, PDO::FETCH_ASSOC for consistent data retrieval, and implements connection pooling through singleton pattern usage. Error logging is implemented throughout to aid debugging while preventing sensitive information exposure to end users.

2) User & Authentication
The User authentication system (`classes/User.php`, `classes/Auth.php`) implements secure user management with dual-table architecture using `User` and `User_2` tables for enhanced data separation. The implementation includes email uniqueness validation, secure password hashing using PHP's `PASSWORD_DEFAULT` algorithm, and comprehensive login validation with `password_verify()`. The `register()` method performs duplicate email and phone number checks before inserting new users with default 'registered user' role. The `login()` method returns structured responses with role-based redirect logic, distinguishing between regular users and administrators. Password reset functionality utilizes token-based authentication stored in the `User_2` table with expiry timestamps, implementing secure token generation and validation through `setResetToken()`, `findByToken()`, and `updatePassword()` methods that maintain data integrity across both user tables.

3) Admin
The Admin module (`Admin/` directory) provides a comprehensive administrative interface with dedicated files for different management functions including `buslisting.php` for bus fleet management, `announcement_display.php` for system announcements, `user_display.php` for user account oversight, and `user_bookings.php` for booking monitoring. The implementation shares authentication mechanisms with the main User class, utilizing role-based access control where admin users are identified by the 'administrator' role in the User table. Admin functions include CRUD operations for buses, routes, and schedules, user account management with booking history access, announcement creation and management, and comprehensive reporting capabilities. The admin interface maintains audit trails for administrative actions and provides real-time monitoring of system activity through integrated dashboards and data visualization components.

4) Route & Stops
Route management is primarily implemented through database queries within the Bus class rather than a dedicated Route class, handling complex route matching logic for Sri Lankan inter-city transportation. The implementation supports flexible route definitions with origin terminals, destination terminals, and intermediate stops stored as comma-separated values in the Route table's Stops field. Route matching algorithms accommodate four distinct travel patterns: direct terminal-to-terminal routes, terminal-to-intermediate-stop journeys, intermediate-stop-to-terminal travels, and stop-to-stop connections with proper sequence validation using `FIND_IN_SET()` MySQL functions. The system validates stop ordering to ensure passengers cannot book return journeys, implements route optimization for multi-stop buses, and maintains route metadata including distance calculations and estimated travel times for accurate scheduling and fare computation.

5) Bus & Schedule
The Bus and Schedule management (`classes/Bus.php`) implements sophisticated search algorithms that handle Sri Lanka's complex inter-city bus route system with terminal and intermediate stop support. The core `searchBusesWithFilters()` method executes complex SQL queries joining Bus, Route, and Schedule tables while calculating real-time seat availability by subtracting confirmed bookings from bus capacity. The implementation supports advanced filtering including fare ranges, departure time windows, minimum seat requirements, and multiple sorting options (fare, time, availability). Schedule management includes dynamic seat calculation, route pattern matching for both direct and multi-stop journeys, and comprehensive validation for travel dates and location inputs. The system prevents past-date bookings, validates origin-destination differences, and implements robust error handling with user-friendly messages while maintaining performance through optimized database queries with proper indexing strategies.

6) Search & Filters (pages)
The search functionality (`pages/search.php`, integrated with `classes/Bus.php`) provides a comprehensive bus discovery interface with real-time availability checking and advanced filtering capabilities. The implementation processes user inputs for origin, destination, and travel date while applying optional filters for fare ranges, departure times, and seat requirements. The search results display includes essential journey information such as departure/arrival times, available seats, fare amounts, and route details with support for both direct routes and multi-stop journeys. The interface implements responsive design using Bootstrap for mobile compatibility, AJAX-powered real-time updates for dynamic filtering, and user experience enhancements including autocomplete for city names, visual seat availability indicators, and comprehensive error messaging. Search results are cached for performance optimization and include booking links that maintain search context throughout the reservation process.

7) Seat Management
Seat management functionality within the Bus class (`classes/Bus.php`) implements dynamic seat layout generation and real-time availability tracking for different bus configurations. The implementation automatically generates default seat layouts when no specific configuration exists, with the first 8 seats designated as lady seats following Sri Lankan bus transport conventions. Real-time seat status is determined through LEFT JOIN operations with the Booking table, filtering by travel date and confirmed booking status to display accurate availability. The system supports flexible seat configurations per bus, implements gender-specific seat reservations with lady seat prioritization, and provides visual seat maps through the booking interface. Seat booking validation includes double-booking prevention, travel date verification, and automatic seat status updates upon successful payment confirmation, ensuring data consistency across concurrent booking attempts.

8) Booking
The Booking system (`classes/Booking.php`) implements comprehensive reservation management with transaction-safe operations and payment integration. The core `createBooking()` method orchestrates multi-step booking processes including input validation, seat availability verification, user creation or retrieval for both registered and guest users, and booking record insertion with unique reference number generation following the 'LT-xxxxxx' format. The implementation includes gender information storage in the complementary `Booking_2` table, automated booking status management through payment lifecycle, and comprehensive error handling with rollback capabilities. Transaction management ensures data consistency during concurrent bookings, guest user support allows anonymous reservations with phone number verification, and booking confirmation includes automated email notifications and PDF ticket generation. The system maintains booking history, supports booking modifications within policy constraints, and implements cancellation workflows with proper audit trails.

9) Payment (PayHere IPG)
The Payment integration (`classes/Payment.php`) implements secure PayHere Internet Payment Gateway connectivity with comprehensive transaction management and security hash validation. The implementation generates dynamic payment forms with proper hash computation using merchant credentials, order identifiers, and amount verification following PayHere's security protocols. Payment processing includes checkout form generation with customer data pre-population, secure hash generation using MD5 algorithms with merchant secret keys, and comprehensive callback handling for successful, failed, and cancelled transactions. The `processPaymentNotification()` method validates incoming payment notifications through hash verification, updates booking status based on payment outcomes, and maintains payment audit trails. Security measures include hash validation for all payment communications, secure credential management through environment variables, and comprehensive logging for financial audit requirements while supporting both sandbox and production environments.

10) Announcements
The Announcements system (`classes/Announcement.php`) provides comprehensive content management for system-wide communications with both public viewing and administrative control interfaces. The implementation includes CRUD operations through methods like `createAnnouncement()`, `getAllAnnouncements()`, `updateAnnouncement()`, and `deleteAnnouncement()` with proper timestamp management for created and updated dates. Administrative interface (`Admin/announcement_display.php`) enables content creation, editing, and removal with rich text support, while public interface (`pages/announcements.php`) displays active announcements with responsive formatting. The system supports announcement scheduling, priority levels for important notices, and automatic archiving of outdated content. Content validation ensures proper formatting and length restrictions, while the display system implements pagination for large announcement volumes and provides search capabilities for historical announcement retrieval.

11) Feedback
The Feedback system (`pages/feedback.php`, `pages/submit_feedback.php`) implements user experience collection with rating systems and comment management for service quality monitoring. The implementation allows both registered and anonymous users to submit feedback with structured rating scales, comment validation, and optional bus-specific feedback linking. Feedback submission includes input sanitization, rating validation within defined ranges, and automated timestamp recording for trend analysis. The system supports feedback categorization by service aspects, implements moderation workflows for inappropriate content, and provides aggregated rating displays for public transparency. Administrative interfaces enable feedback monitoring, response management, and comprehensive reporting for service improvement initiatives. Data analytics features include rating trends, comment sentiment analysis, and feedback volume tracking to support operational decision-making and customer service enhancement programs.

12) Incidents
The Incidents management system (`pages/incidents.php`, `pages/submit_incidents.php`, `pages/manage_incidents.php`) implements comprehensive issue reporting and resolution tracking for operational support. The implementation supports incident reporting by users with booking reference linking, detailed description capture, and automatic status tracking through predefined workflows from 'submitted' through 'in progress' to 'resolved'. Administrative management includes incident assignment, status updates, resolution recording, and automated notification systems for status changes. The system maintains comprehensive audit trails with timestamps, responsible personnel tracking, and resolution documentation. Priority classification enables urgent incident escalation, while automated escalation procedures ensure timely response to critical issues. Reporting capabilities include incident volume analysis, resolution time tracking, and recurring issue identification to support operational improvements and customer service optimization.

13) Booking Cancellation
The Booking Cancellation system (`classes/BookingCancellation.php`) implements policy-compliant cancellation workflows with automated refund processing and comprehensive audit trails. The implementation processes cancellation requests with policy validation, refund calculation based on cancellation timing and terms, and integration with PayHere gateway for automated refund processing. Administrative oversight includes cancellation approval workflows, refund authorization, and comprehensive status tracking through `ProcessedBy` and `ProcessedAt` fields. The system supports partial refunds based on cancellation policies, maintains cancellation reason tracking for analytics, and implements automatic notification systems for cancellation confirmations. Financial integration ensures proper refund processing through payment gateways, while audit capabilities provide comprehensive cancellation reporting for business intelligence and customer service optimization.

14) Location
Location management serves as the foundational geographic reference system supporting the route and stop infrastructure through database-driven location registries. The implementation maintains comprehensive location data including terminal cities, intermediate stops, and geographic coordinates for route planning and optimization. Location validation ensures data consistency across route definitions, supports location autocomplete functionality in user interfaces, and maintains hierarchical location relationships for administrative regions. The system includes location metadata such as facilities available, accessibility features, and operational hours for passenger information. Geographic data integration supports distance calculations, route optimization algorithms, and travel time estimations for accurate scheduling and fare computation throughout the Lanka Transit network.

15) Page Wiring (UI/UX)
The presentation layer implements responsive web design using Bootstrap framework with consistent navigation and user experience across all application modules. The implementation includes shared layout components (`includes/header.php`, `includes/footer.php`) providing consistent branding, navigation menus, and responsive design patterns. User journey flows connect search functionality through booking completion with payment processing, maintaining session state and user context throughout multi-step processes. The interface supports both desktop and mobile users with adaptive layouts, implements accessibility standards for diverse user needs, and provides comprehensive error handling with user-friendly messaging. Administrative interfaces maintain separate styling and navigation patterns optimized for operational workflows, while public interfaces prioritize ease of use and conversion optimization for booking completion and customer satisfaction.
